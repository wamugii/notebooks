# WAMUGII AI Program — lesson notebooks

Every coding lesson of the [WAMUGII AI Program](https://wamugii.kento.rw/courses) as a notebook you can open in **Google Colab** with one click: free, nothing to install, and a free GPU for the deep-learning lessons.

**How to use:** click **Open in Colab**, then run the cells from top to bottom (**Runtime → Run all**). To keep your work, choose **File → Save a copy in Drive**. Lessons that call an AI model need an API key: add it with the key icon (**Secrets**) in Colab's left bar and switch on notebook access.

These notebooks are generated from the course lessons. To report a problem, use the questions box under the lesson on the website.
